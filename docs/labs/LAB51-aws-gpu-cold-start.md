## Цель

[ЛР47](LAB47-k8s-gpu-eks-autoscaling.md) показывает, из чего складывается время появления GPU-реплики. Здесь это время сокращается по одной статье за раз, и для каждой меры считается выигрыш и цена. Это ответ на вопрос «как быстро вы переживёте всплеск трафика», который задают руководителю инфраструктуры сервинга.

## Проверяемая гипотеза

1. Образ в ECR того же региона через endpoint и веса из S3 через endpoint вместе сокращают время от NodeClaim до readiness не меньше чем на 30% относительно базовой линии ЛР47.
2. Предзагрузка образа и весов на узел сокращает время ещё не меньше чем на 30%, но добавляет постоянную стоимость (хранение снапшота или простаивающий диск), которую нужно посчитать в USD в месяц.

Пороги, модель (идентификатор, ревизия, размер), тип инстанса и AMI фиксируются в протоколе до прогона.

## Подготовка

- Прочитайте: документацию Karpenter по EC2NodeClass (`blockDeviceMappings`, `amiSelectorTerms`, user data), документацию EKS по GPU AMI, Amazon ECR (репликация, сканирование), загрузку моделей в vLLM из локального пути и из S3.
- Повторите расходные правила ЛР47: бюджет, `limits` в NodePool, цена инстанса с датой.
- Код и манифесты — в `experiments/k8s-gpu/terraform/` и `experiments/k8s-gpu/manifests/LAB51/`, изменения поверх кода ЛР47.

```bash
npm run lab:new -- --lab LAB51 --session aws-01
LAB_DIR='experiments/aws/measurements/LAB51-aws-01'
```

## Порядок выполнения

1. **Базовая линия.** Повторите измерение ЛР47 для одного холодного узла: pod создан → NodeClaim → инстанс → `Ready` → `nvidia.com/gpu` → образ скачан → веса загружены → readiness. Три повтора, медиана.
2. **Образ.** Перенесите образ vLLM в ECR своего региона; соберите облегчённый вариант (только нужные компоненты), запишите размеры. Повторите замер.
3. **Веса.** Загрузите веса из S3 через gateway endpoint в локальный NVMe или EBS узла (init container или sidecar) вместо скачивания с Hub. Повторите замер.
4. **Предзагрузка.** Подготовьте снапшот EBS с образом и весами и подключите его в EC2NodeClass, либо DaemonSet предзагрузки на прогретом узле. Повторите замер и посчитайте месячную стоимость хранения.
5. **Итог.** Сравните медианы, разложите выигрыш по этапам. Если гипотеза 1 из ЛР47 была отвергнута (образ и веса занимали меньше половины), объясните, почему меры этой работы дают мало.
6. **Teardown.** `terraform destroy`, удаление снапшотов и образов ECR, если они не нужны дальше, `janitor.sh` из ЛР48.
