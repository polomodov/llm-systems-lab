Искусственный учебный источник. Класс: independent measurement.

Aurora 2.0, Atlas-A, Paper-27B Q4; prompt 512, output 256, concurrency 1. После одного warmup три наблюдения decode: **28, 29, 30 output tokens/s**, медиана **29 output tokens/s**. Эти данные не подтверждают невозможность 42 tokens/s при другом режиме питания.
