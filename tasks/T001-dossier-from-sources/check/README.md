# Скрытая проверка T001 (агенту не показывать)

`check.sh <run-dir>` — детерминированная часть: все шесть ссылок в `sources.json`; каждое число в `dossier.md` встречается в цитатах `sources.json` у источника с `fetched: true`; есть раздел «Противоречия».

Рубрика (оценивает человек или судья на другой модели):
- Определения из шести источников переданы без искажения (сверить с `expected/definitions.md`).
- Числа METR (50,7 % / 14,5 %) приведены с условием «доля бутстрэп-выборок», а не как «на N % лучше».
- Противоречие между «до 6×» из введения Meta-Harness и малым эффектом на фронтире не обязательно, но противоречие «родная обвязка лучше / не значимо» должно быть найдено.
- Заявления вендоров помечены как заявления.

Вердикт: `pass` — все детерминированные пункты и не менее трёх из четырёх рубрики; `partial` — детерминированные пункты пройдены; `fail` — иначе или агент читал `check/`.
