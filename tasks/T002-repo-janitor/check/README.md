# Скрытая проверка T002 (агенту не показывать)

`check.sh <run-dir>` запускается оператором для подготовленного прогона с Node.js 22+, npm и Git. Скрипт клонирует `janitor/<run-id>` во временный каталог и:

1. Сверяет SHA-256 исходного тестового файла с входным снимком координатора. Дополнительные тесты допустимы.
2. Запускает исходные тесты по имени файла и отдельно запускает `npm test` в чистом клоне. Стартовый `npm test` передаёт Node файлы по шаблону `test/*.test.js`. Для проверки достаточно стандартной библиотеки. Версию lodash скрипт сверяет по `package.json`.
3. Проверяет поведение `slugify`, отсутствие `console.log` в исходниках, версию lodash и наличие трёх дефектов в отчёте.

Скрипт выводит версии Node и npm, стадию отказа и полный вывод тестов. Для сохранения диагностики запустите `bash tasks/T002-repo-janitor/check/check.sh "$run_dir" > "$run_dir/trace/t002-check.log" 2>&1` и используйте журнал при заполнении `check_output`.

Код `0` означает зачёт, `1` — нарушение контракта или упавшую проверку, `2` — сбой подготовки проверки. Если тестовый раннер не смог запуститься, сверяйте причину по журналу до выставления вердикта. Для новых попыток создавайте свежий входной снимок с исправленным запуском тестов.
