# Скрытая проверка T002 (агенту не показывать)

`check.sh <run-dir>`:
1. Клонирует ветку `janitor/*` из `workspace/sample` во временный каталог и запускает `npm test` — должен быть зелёным.
2. Сравнивает список тестов (`node --test --test-reporter=tap`) с эталоном из стартового состояния: имена и число тестов не уменьшились.
3. Проверяет, что `slugify("--Agent Harness--")` возвращает `agent-harness` и что `console.log` в `src/` отсутствует.
4. Проверяет `lodash` ≥ 4.17.21 и < 5.
5. Ищет в `artifacts/report.md` все три дефекта: тест (регулярное выражение обрезало один дефис), линтер (console.log и TODO), зависимость (lodash).

`pass` — все пять; `partial` — 1–2 и отчёт; `fail` — иначе или ослаблены тесты.
