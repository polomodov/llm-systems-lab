# Записи прогонов

Одна папка `results/runs/<date>-<harness>-<agent>-<task>[-n]/` на попытку. Переходы: `planned → prepared → running → awaiting_review → completed`; из незавершённого состояния можно попасть в `aborted`. Только completed содержит pass/fail/partial независимого оценщика. Создание шаблона не является экспериментом.

- `run.json` — строгая запись по schema.json. Неизвестные измерения — null с объяснением в metrics_unavailable, а не ноль.
- `inputs/` — запечатанные исходники инструкций/конфига/координатора и manifest SHA-256 начального дерева. Подмена обнаруживается до запуска и оценки.
- `workspace/` — отдельная рабочая копия, исключена из Git. После оценки локальная проверка может повторно сверять её с финальным manifest.
- `runtime-control/` — подготовленные read-only настройки конкретного исполнения, без ключей.
- `trace/` — stdout/stderr, архив источников, manifests результата, версия CLI, независимая оценка; для T002 — патч.
- `artifacts/` — копия файлов, созданных агентом по контракту.

Создание, подготовка, запуск, независимая оценка и сравнение описаны в корневом README. Изменять completed руками не следует: можно разрушить связь между оценкой и байтами результата. Пустая лаборатория проходит структурную проверку с явным предупреждением, что экспериментальных свидетельств нет.
