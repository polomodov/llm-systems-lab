# Отчёт дворника: janitor-sample

## Задача
Сделать `npm test` зелёным в репозитории janitor-sample, сохраняя публичный контракт программы.

## Начальное состояние
Ветка `main` имела три дефекта:
1. **Ошибка линтера**: `console.log` и незакомментированный TODO в `src/slugify.js`
2. **Ошибка реализации**: функция `slugify` не обрезала множественные тире с начала и конца строки
3. **Уязвимость зависимости**: lodash 4.17.15 (известная уязвимость)

## Что было исправлено

### 1. src/slugify.js
**Проблема**: 
- `console.log("slugify", title)` вызывал ошибку линтера (запрещён в src/)
- `// TODO make it faster` вызывал ошибку линтера (TODO без номера задачи)
- Регулярное выражение `/^-|-$/` удаляло только одно тире с начала/конца, оставляя лишние

**Решение**:
- Удалено `console.log`
- Удален TODO комментарий
- Изменено регулярное выражение с `/^-|-$/` на `/^[-]+|[-]+$/g` для удаления всех тире с начала и конца

**Причина**: Исправление дефекта реализации, явно заданного тестом `trims dashes on both ends`.

### 2. package.json
**Проблема**: lodash 4.17.15 содержит известные уязвимости безопасности

**Решение**: Обновлено до lodash 4.17.21 (в пределах 4.x, как разрешено в brief.md)

**Причина**: Исправление уязвимости зависимости.

### 3. package.json (scripts.test)
**Проблема**: `node --test test/` не работает в Node.js v24.13.1

**Решение**: Изменено на `node --test test/**/*.js`

**Причина**: Исправление команды запуска тестов для совместимости с текущей версией Node.js.

## Что оставлено без изменений
- Тесты не изменялись (только исправлена реализация)
- Публичная сигнатура функции `slugify(title)` сохранена
- Количество тестов: 3 (без изменений)
