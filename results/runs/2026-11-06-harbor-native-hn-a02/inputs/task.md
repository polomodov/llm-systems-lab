# Native Harbor normalization qualification

This is a separate synthetic infrastructure episode. The public instruction and
input are packaged with this contract; only the declared result artifact crosses
into the independent verifier. Existing laboratory campaigns are unchanged.

## Budget

Up to 8 turns or $2. Agent execution has a 180-second external timeout; verifier
execution has a 60-second timeout. These values are read from the sealed contract.
Native turn/step definitions and enforcement differ. USD is an observed target,
not a universal hard provider cap. Failed requests consume actual spend.

## Conditions

Run as UID 1000 with a fresh private HOME and a frozen harness image. Only the
selected provider API may be reachable during a later authorized real attempt.
Offline fixtures use no real credentials and cannot authorize paid execution.
The separate verifier has no provider credentials or agent workspace mount.

## Evidence and evaluation

Preserve native terminal logs, declared ATIF schema, requested and observed model
identity, usage and independently attributable billing. Missing measurements are
null with explanations. A native reported estimate is not settled billing.
The verifier checks the declared artifact against its frozen expected result.
Infrastructure/identity failures are aborted; complete task output is graded
independently. A pass without identity or billing evidence remains unqualified.

## Stop

Stop on timeout, observed model mismatch, boundary violation or missing terminal
evidence. Preserve every started attempt and its cost; never overwrite or retry
an attempt implicitly. Reconcile billing before admitting the next paid slot.
