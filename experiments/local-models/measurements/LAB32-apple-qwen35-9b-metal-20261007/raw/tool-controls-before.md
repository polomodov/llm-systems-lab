# Два диагностических контроля до исполнения

Исходный warmup tool после восьми short chats вернул content10/stop безtool_calls, хотя runtime supports_tools. Не приписывать отказ tensor/модели/режиму thinking без проверки. Контролируем два отдельных свежих server8K с тем же binary/tensor/model/seed/temp/cachefalse: (1) fresh-no-thinking, одна tool JSON попытка; (2) fresh-thinking-auto, единственное runtime/input отличие — reasoning auto и enable_thinking=true. Одна попытка/режим не составляет допуск LAB08 или триповторную LAB32 серию. Exact requests/outputs/client validation и reasons сохранить, не повторять failures. Shutdown только одному верифицированному child PID; SIGINT группе через time в штатном завершении не использовать. Nativeexit0 обязателен. Timer180s, power/memory admission до/после, RSS/time peak; эти короткие controls без отдельного 2s sampler, так что transient memory/power события ими не проверяются.
