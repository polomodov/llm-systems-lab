# LAB03 — предварительный протокол проверки gpt-oss-120b (preregistration)

Записан ДО перепроверки артефакта. Момент регистрации подтверждается отдельным
git-коммитом до коммита с результатами.

## Гипотеза

Локальная копия `gpt-oss-120b-MXFP4.gguf` совпадает с публикацией
`ggml-org/gpt-oss-120b-GGUF@238abdd290bb874b90a5da1b4549881b7d05c091`
по байтовому размеру (63 387 346 208 B) и SHA-256
(`582bd40f6886200101f4c4ed9f25f3fe80cc14c86e9e2b37746cd8904a0c622d`), то есть является
воспроизводимым закреплённым артефактом для LAB04/LAB05.

## Фактор и константы

- Фактор: нет (детерминированная проверка целостности).
- Константы: закреплённая ревизия, ожидаемые `bytes`/`sha256` из `raw/artifact.json`,
  путь хранения `$LAB_STORAGE/ggml-org/gpt-oss-120b-GGUF/<rev>/`.

## Порядок

1. Offline-проверка существующего файла скриптом `raw/fetch_artifact.py`
   (без `--download`): пересчитать SHA-256 и размер, сравнить с publisher.
2. Сохранить `raw/verification.json` в формате
   `{repository, revision, files:[{path, bytes, sha256, publisher_hash_present, status}]}`.
3. Оформить `raw/weights.sha256` для `sha256sum --check` в LAB04/LAB05.

## Критерий остановки и решение

- Расхождение размера/SHA → `status: fail`, артефакт дальше не передаётся.
- Отсутствующий файл → `no-artifact`, не размер 0.
- Успех: все файлы `status: verified`; гипотеза поддержана.

## Расширения

Повторная верификация идемпотентна. Реальный inference — вне LAB03 (LAB04/LAB05).
