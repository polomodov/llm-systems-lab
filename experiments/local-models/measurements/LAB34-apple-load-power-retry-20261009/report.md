# LAB34 — второй retry после восстановления AC

Сессия `apple-load-power-retry-20261009`. Статус **in-progress, подготовка**.

## Паспорт выполнения

M5 Max / 128 GiB / macOS 26.5, native GGUF Qwen3.5-9B Q6_K, patched llama.cpp b8407/tile16/Metal. Полные параметры и hashes в [протоколе](raw/protocol.md). Новый runtime manifest после старта. Агентных попыток нет, run_ids=[].

## Гипотеза и протокол до запуска

После восстановления AC новый resident deployment завершит пять оставшихся коротких клеток и ≥1800 секунд sustained. Сохраняются оба предыдущих failed r2-c4; их retries не заменяют первичную evidence. Перед новым запуском — отдельные admission samples AC/mode 0 за две минуты. Девять успешных клеток будут происходить из двух сессий; история остановок включает три процесса.

## Ход выполнения

Подготовлены десять planned attempts, неизменное тело запроса и source hashes. Четыре исторические клетки 08.10 проверяются offline. Перед GPU-стартом проверяются стабильное AC, memory guard, чужие модели, порт и binary/model hashes.

## Результаты

Новых измерений нет; TSV пока содержит заголовок. Для двух предыдущих сессий начаты 76 запросов, три ошибки; копии исторических блоков не прибавляются к этой сумме. Результаты этой новой сессии будут добавлены отдельно после выполнения.

## Ошибки и ограничения

Первая кампания получила SIGKILL неизвестного происхождения; первый retry остановлен guard после перехода на батарею и завершился с одним SIGINT / native exit 0. Оба отчёта остаются blocked. TTFT, энергия, температура и максимальный GPU budget неизвестны.
