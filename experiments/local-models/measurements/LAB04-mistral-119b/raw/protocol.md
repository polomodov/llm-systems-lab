# LAB04 — протокол backend-сравнения (session mistral-119b)

Модель: mistral-small-4-119b UD-Q4_K_M (3 shard). Движок: prebuilt llama.cpp
b8407 (`312cf0332`), два бандла — Vulkan (GNU 11.4) и ROCm/HIP gfx1151 (GNU 13.3).

План до измерений:

1. Проверить `weights.sha256` (ЛР03) до запуска.
2. Зафиксировать help/devices/version и SHA бинарей обоих бандлов.
3. Один прогревочный прогон на каждый backend (не входит в статистику).
4. Три повтора на backend, чередуя порядок; в каждом — pp2048 и tg128 при глубине
   4096; `/usr/bin/time -v` для RSS, `/proc/vmstat` до/после, фоновая серия
   `vmstat -w 1`.
5. Константы: `-ngl 999 -t 8 -b 512 -ub 256 -ctk f16 -ctv f16 -fa 1`.
6. Остановка ветви: OOM, GPU reset, устойчивая подкачка, незавершённый прогон.
7. Отсутствие ветви — blocker, не преимущество другой.

Дополнительное правило для толстой модели: если backend не завершает минимальный
прогон (`-p 64 -n 16`) за разумное время (>15 мин), ветвь помечается blocked с
сохранением лога, чтобы не тратить часы GPU.
