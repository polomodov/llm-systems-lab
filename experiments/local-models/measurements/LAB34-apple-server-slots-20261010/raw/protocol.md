# LAB34 — фактические серверные слоты

Новая серия после прежней проверки очереди клиентов на одном слоте. Артефакт Qwen3.5-9B GGUF Q6_K, revision 3885219b6810b007914f3a7950a8d1b469d598a5; llama.cpp commit 312cf03328496df9c56fe843952cf02a8964c59a, Metal tensor tile16. До каждого Popen проверяются SHA-256 весов, 23 файлов движка (21 путь dylib) и паспорта. Дополнительная bundled dylib запрещает запуск. Логи должны подтвердить M5 Max, offloaded 33/33 и tensor=true.

Холодные серверы: slots 1 → 2 → 4. Общий контекст -c=slots×8192, -np=slots; фактические props.total_slots и slots[*].n_ctx подтверждают 8192 на каждом слоте. Параметры: no-context-shift, Jinja, reasoning auto, thinking=true, offload=999, threads=8, batch=512, ubatch=256, KV=f16/f16, flash attention=on, no-cache-prompt, cache-ram=0 (последний флаг подтверждён pinned help). Один собственный сервер на 127.0.0.1:18080.

Одинаковый публичный запрос: текст 300 слов, output cap=512, temperature=0, seed=1, top_p=1, JSON без streaming. Это новая конфигурация; прежний output=2048 не является прямым контролем. Finish length допустим для нагрузки, но не означает успешное качество ответа.

Для каждой конфигурации: прогрев одной волной (requests=slots), затем три когорты (requests=3×slots, client concurrency=slots). Между ними очередь должна быть пустой. Slot sampler каждые 50 мс: в каждой когорте число одновременно processing слотов должно достигать slots. Это наблюдение логического параллелизма сервера, не одновременного исполнения GPU kernels. Driver без retries, tools и auth; body ≤64 KiB, response ≤1 MiB, timeout и p95 ≤90 с, ошибок 0. Usage берётся из первичного ответа, отсутствующее значение остаётся null.

Только после всех коротких проверок: 30 минут на slots=4/concurrency=4/output=512. Когорты по 12 запросов до ≥1800 с, последнюю дождаться; общий deadline sustained=2100 с. До запуска baseline free+spec ≥24 GiB; после hashing допуск повторяется. Во время исполнения: free+spec ≥8 GiB, pressure level=1, free percentage ≥50, swap=0, AC/mode=0, owned RSS ≤24 GiB; resource samples каждые 2 с, gap ≤15 с, обратный ход часов запрещён. Короткая серия ограничена 900 с на конфигурацию. Caffeinate действует только для собственного процесса. Чужие модели и занятый порт означают отказ; настройки ОС и чужие процессы не меняются.

Cleanup: идемпотентный SIGINT собственной process group, 30 с на завершение, затем собственный SIGKILL при превышении. Клиент также принадлежит этому контроллеру. Ошибка сохраняется, следующие попытки not-run; повтор под старым ID запрещён. Температура, энергия, максимальный GPU budget и TTFT неизвестны. Полная latency ответа не называется TTFT. Агентных попыток здесь нет.
