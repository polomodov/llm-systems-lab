# Antigravity CLI (бывший Gemini CLI)

Статус на машине: не установлена; установщик на дату среза не проверен (https://antigravity.google). С 18.06.2026 заменяет Gemini CLI для бесплатного тарифа; Gemini CLI остаётся открытым (Apache-2.0) и может быть запасным вариантом: `npm i -g @google/gemini-cli`. Модель привязана (Gemini 3.x).

## Первый прогон
A1 на T001 с `model_lock: true`; интересуют песочница терминала и маскирование учётных данных, заявленные для CLI.
