# SPACE: песочницы Firecracker как среда исполнения агентов

> **Заморожено 05.11.2026.** Методичка сохранена как есть, но новые сессии `lab:new` для неё не создаются: ветка SPACE не имеет измерений и реализации и выделяется в отдельный учебный репозиторий. Снятие заморозки требует отдельного решения и записи в [статусе практикума](../../docs/labs/README.md#заморозка-инфраструктурных-веток).

Каталог ветки [ЛР36–42](../../docs/labs/README.md#маршрут-space). [SPACE](https://github.com/polomodov/SPACE) — открытая платформа песочниц на Firecracker microVM (форк `perplexityai/SPACE`, Apache 2.0). Здесь проверяется, как она работает под агентными обвязками этой лаборатории. Это не обвязка: `harness.json` в каталоге нет и быть не должно.

Статус: **методички готовы, измерений нет**. Совместимость SPACE со стендами `unverified` до первой сессии ЛР36. Backend раннера для SPACE пока не реализован; ЛР37 создаёт его.

## Стенды

| Стенд | Машина | Роль |
| --- | --- | --- |
| A, сессии `ryzen-NN` | Ryzen AI Max+ 395 / 128 GB / Linux, тот же, что в ЛР02 | Полный smoke, кампании, агенты с локальной моделью |
| B, сессии `honor-NN` | HONOR MagicBook X16, Ryzen 7 PRO 8845HS / 32 GB / Ubuntu | Минимальный профиль и поиск предела по памяти |

Обоим нужен Linux x86_64 с `/dev/kvm` (AMD-V включён в BIOS), `/dev/net/tun`, Docker с privileged-контейнерами, loop-устройства и btrfs. Требования и шаги установки — в `docs/installation.md` репозитория SPACE.

## Что лежит здесь

| Путь | Содержимое | Появляется в |
| --- | --- | --- |
| `measurements/LABxx-session/` | Отчёты; создаются `npm run lab:new -- --lab LAB36 --session ryzen-01` | ЛР36–42 |
| `recipes/` | Рецепты шаблонов SPACE из образов обвязок | ЛР37 |
| `tools/` | Сервер инструментов exec/files поверх SPACE API | ЛР38 |
| `bench/` | Измеритель времени до первой команды | ЛР40 |
| `egress/` | Egress-профиль и синтетические пробы | ЛР41 |
| `campaign/` | Планировщик параллельной серии | ЛР42 |

Подкаталоги создаются той работой, которой они нужны. Каждый компонент, добавленный в обвязку или раннер, получает строку в [реестре](../../docs/harness-ledger.md) в том же изменении.

## Правила

- Версия SPACE закрепляется commit-хэшем в каждом отчёте; шаблоны — по digest образа и content hash шаблона.
- Bearer-токены SPACE, пароль консоли и ключи провайдеров не попадают в отчёты, raw и коммиты.
- Изменения конфигурации относятся только к локальному Kind своего стенда.
- Цифры из документации SPACE — заявления разработчиков платформы; собственные измерения указываются с run ID или сессией.
