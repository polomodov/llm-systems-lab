# Эксперименты по обвязкам

Одна папка на обвязку. Внутри: `README.md` (установка, запуск, где лежит конфиг), `NOTES.md` (наблюдения по прогонам), конфигурация обвязки и `agents/<code>/` — реализация агентов под эту обвязку.

Первая обязанность конфигурации любой обвязки — запретить агенту чтение `tasks/*/check/`. Пока запрет не реализован стеной (хук, право, песочница), прогоны в этой обвязке не считаются.
